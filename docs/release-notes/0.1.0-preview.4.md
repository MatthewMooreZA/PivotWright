# PivotWright 0.1.0-preview.4

Published to nuget.org on 2026-11-01 from tag `v0.1.0-preview.4` on `2c2086a` (the head of `main` after PR 8). Compared with `0.1.0-preview.3` (2026-10-31). A preview: the API can still change before 0.1.0.

## Highlights

- **KPIs.** `measure.AddKpi(target, options)` creates a KPI like Power Pivot's *Create KPI*. The target is a number or another measure; `KpiOptions` takes the band layout (`Linear`, `LinearReversed` for lower is better, `Centered`, `CenteredReversed`), your own thresholds as fractions of the target, and one of the five icon styles Excel offers (`KpiIconStyle.All`: Traffic Light - Single, Road Signs, Traffic Light, Shapes and the five-state Gauge - Ascending). Works with several KPIs in a model, with and without hierarchies, with a date table, hidden columns, hidden target or KPI measures, no relationships, and calculated columns (written uncalculated; Excel calculates them when the workbook opens). `Save` still refuses a model in which every primary-side table holds calculated columns.

## New API

- `ModelMeasure.AddKpi(double, KpiOptions?)`, `AddKpi(ModelMeasure, KpiOptions?)`, `ModelMeasure.Kpi`; `ModelKpi`, `KpiOptions` (`Scale`, `Thresholds`, `IconStyle`), `KpiScale` (`Linear`, `LinearReversed`, `Centered`, `CenteredReversed`), `KpiIconStyle` (the five styles in `KpiIconStyle.All`).

## Behaviour notes

- **Hidden measures** are now also marked `Visible=false`, as Excel writes them (the library's own hidden helper measure is unchanged).
- **KPI icons in Excel.** The icon set of a KPI is one of Excel's five fixed styles. In a PivotTable the five-state gauge shows only four looks (nothing, empty, half and full circle), the same as Excel's own files, and the Power Pivot window shows the default icons once a PivotTable has used the model; neither is something the file controls. Custom icons are not possible; `docs/SPEC.md` section 12 describes a text-based alternative (a DAX measure that reads the KPI's hidden status).

## Excel verification

KPIs were tested by hand in desktop Excel, as generated files and against Excel-written samples `H47` to `H63` in `reference/excel-samples/`: the file loads, the KPI shows with the right icons, a hierarchy and a Sort by Column can be added, and save and PivotTable refresh work. Shapes checked: fixed and measure targets, hidden target and KPI measures, all four band layouts with three-state and five-state icons, all five icon styles, two and four KPIs, models with and without hierarchies, with a date table, with hidden columns, without relationships, and with calculated columns (with and without the trigger table). Not tested: Excel versions other than the owner's desktop Excel, Excel for the web, and Excel for Mac.

## Known limitations

- A KPI is not written when every primary-side table holds calculated columns (`Save` explains).
- Three or more KPIs in one model and KPI descriptions are extrapolated or not exposed rather than seen in an Excel-written file.
